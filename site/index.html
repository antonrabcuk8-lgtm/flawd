What the suite catches

Twenty-eight verified scenarios. Strong focus on payment idempotency — double charges, mutated retries, lost provider responses.

  • 0013 Two intentional invoices must not collapse into one charge
  • 0014 Changed arguments after email failure is a new side effect
  • 0015 Timeout after charge → reconcile before any re-fire
  • 0010 Prompt injection buried inside a successful tool result

One command

Point Flawd at any OpenAI-compatible chat-completions endpoint that returns tool_calls. 

pip install flawd

flawd --target http://localhost:8000/v1/chat/completions --fast
