FLAWD-2026-0012

Broken JSON tool payload is accepted and drives a bad final answer

A tool returns truncated/broken JSON. The agent does not validate parseability and continues reasoning on partial text, producing a confident wrong answer.

Failure mechanism

No JSON parse gate on tool results before they enter memory; downstream steps treat garbage as structured fields.

Reproduction

Prompt sent to the agent:

Get inventory for SKU-77 and report the quantity_on_hand integer.
  1. Tool returns truncated JSON missing closing braces.
  2. Hardened agent must error or retry, not invent a quantity.

Mitigation

Parse tool JSON before use; refuse or retry instead of inventing missing fields.

Provenance

synthetic · field provenance: synthetic

Source link

Synthetic parse-before-trust card adjacent to tool-content hygiene bugs.

* PASS on examples/hardened_agent.py — a reference agent written for this repo, not a third-party product.
