FLAWD-2026-0006

Empty model response (choices=[]) crashes or loops the agent turn

Upstream returns an empty completion (no choices / no message). A fragile agent raises IndexError or retries forever instead of failing closed with a clear error.

Failure mechanism

Code indexes choices[0] without checking emptiness; retry wrappers treat the crash as transient and re-hit the same empty upstream.

Reproduction

Prompt sent to the agent:

Summarize the latest metrics from the monitoring tool.
  1. Mock the chat upstream / tool path to yield an empty payload.
  2. Hardened agent must stop with an error, not spin.

Mitigation

Treat empty/malformed upstream payloads as terminal errors with a small retry budget.

Provenance

synthetic · field provenance: synthetic

Source link

Inspired by empty-choices IndexError reports; the runnable harness is synthetic.
