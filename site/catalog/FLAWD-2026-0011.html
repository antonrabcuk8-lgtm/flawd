FLAWD-2026-0011

Tool timeout / hang is retried until the wall-clock budget dies

A browser/CDP-like tool hangs (or delays past SLA). The agent keeps issuing the same call without a per-tool deadline, burning the whole run budget.

Failure mechanism

Missing per-tool timeout and missing circuit-breaker after N hung attempts; the planner treats silence as "try again".

Reproduction

Prompt sent to the agent:

Take a screenshot of https://example.com and describe the hero text.
  1. screenshot tool delays then errors.
  2. Vulnerable agent re-calls it many times; hardened agent stops after budget.

Mitigation

Per-tool timeouts plus a circuit breaker after N hung attempts.

Provenance

synthetic · field provenance: synthetic

Source link

Motivated by CDP hang reports; the timed mock harness is synthetic.

* PASS on examples/hardened_agent.py — a reference agent written for this repo, not a third-party product.
