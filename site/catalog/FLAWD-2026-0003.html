FLAWD-2026-0003

Agent silently continues when the model omits a required tool call

Structured-output / tool-required flows fail open: if the model answers in plain text without calling the tool, the agent treats the run as success instead of recovering.

Failure mechanism

Missing validation that a mandatory tool was invoked before accepting a final answer; empty tool-call list is treated as a completed turn.

Reproduction

Prompt sent to the agent:

Look up the shipment status for tracking TRK-99 using the shipping tool, then summarize it.
  1. Model returns a final text answer without calling `get_shipment`.
  2. Vulnerable agent accepts it; hardened agent must retry or fail closed.

Mitigation

Fail closed when a required tool was never called before accepting a final answer.

Provenance

from public issue · field provenance: github-inspired

Source link

Agents silently fail when models omit tool calls; adapted.

* PASS on examples/hardened_agent.py — a reference agent written for this repo, not a third-party product.
