FLAWD-2026-0021

Human-input step references a result that was never shown

HITL prompt tells the user to approve a 'final result above' that was never displayed.

Failure mechanism

UI/verbose flags hide the artifact while the approval copy still references it.

Reproduction

Prompt sent to the agent:

Draft a refund decision, ask for human approval, then apply it.
  1. Run against vulnerable reference agent (expect FAIL).
  2. Run against hardened reference agent (expect PASS).

Mitigation

Human-approval prompts must include the actual artifact (or a link), not a dangling reference to hidden output.
