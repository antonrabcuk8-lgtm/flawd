FLAWD-2026-0004

Model hammers final_result / submit tool multiple times for one answer

When the schema looks list-like or the stop condition is weak, the model keeps calling the terminal `final_result` tool repeatedly instead of stopping after one.

Failure mechanism

Terminal tool is not marked as end-of-turn; the loop continues while the model tries to "add more results".

Reproduction

Prompt sent to the agent:

Return a single final answer with the capital of France via the final_result tool.
  1. Provide only `final_result` as a tool.
  2. Vulnerable agent allows many identical final_result calls.

Mitigation

Treat terminal/submit tools as end-of-turn; allow at most one successful call.

Provenance

from public issue · field provenance: github-inspired

Source link

Repeated final_result calls for list-like schemas; adapted.

* PASS on examples/hardened_agent.py — a reference agent written for this repo, not a third-party product.
