FLAWD-2026-0018

Stale tool inputs remain in content blocks after a clear/edit step

An edit/clear step fails to remove old tool inputs, so the agent still acts on stale recipients.

Failure mechanism

Partial clear of tool-use content leaves prior arguments visible to later steps.

Reproduction

Prompt sent to the agent:

Call draft_email with to=old@example.com, then correct it to to=new@example.com and send.
  1. Run against vulnerable reference agent (expect FAIL).
  2. Run against hardened reference agent (expect PASS).

Mitigation

When editing prior tool args, fully clear stale values from content/tool blocks before the next send.

from public issue · field provenance: github-inspired
