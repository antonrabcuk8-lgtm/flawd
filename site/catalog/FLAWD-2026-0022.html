FLAWD-2026-0022

Invalid tool timeout/retry config is accepted and causes hang-like behavior

A toolset accepts timeout<=0 or negative retries, then the run hangs or retry-storms.

Failure mechanism

Missing config validation for tool timeout/retry parameters.

Reproduction

Prompt sent to the agent:

Call slow_lookup for key=alpha.
  1. Run against vulnerable reference agent (expect FAIL).
  2. Run against hardened reference agent (expect PASS).

Mitigation

Validate timeout and max_retries at configuration time; reject non-positive budgets before the run starts.

Provenance

from public issue · field provenance: github-inspired
