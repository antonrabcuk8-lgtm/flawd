FLAWD-2026-0013

Two intentional identical charges must both execute (false-positive guard)

Control test: the user intentionally requests two separate payments with the same amount. An over-aggressive idempotency layer must not collapse them into one charge.

Failure mechanism

Deduping only on argument fingerprint treats two legitimate actions as duplicates.

Reproduction

Prompt sent to the agent:

Charge 10.00 USD for invoice INV-A, then charge 10.00 USD again for invoice INV-B. Both payments are intentional and must both complete.
  1. Agent should call charge_card twice with distinct logical action ids.
  2. Failing agent calls charge_card only once and claims both invoices paid.

Mitigation

Scope idempotency keys to a logical action id (invoice id / intent id), not only to raw tool argument equality. Same amount twice with different action ids must both run.
