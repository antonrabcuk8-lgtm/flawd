FLAWD-2026-0009

HTTP 429 from a tool triggers an unbounded retry loop

A tool returns 429 Too Many Requests. The agent ignores Retry-After / budget and immediately re-calls the same tool until tokens or wall-clock explode.

Failure mechanism

No rate-limit aware backoff; transient HTTP errors are treated as ordinary recoverable tool failures with tight retry.

Reproduction

Prompt sent to the agent:

Get the current weather for Kyiv using the weather tool.
  1. weather_api always returns 429.
  2. Vulnerable agent repeats the call many times quickly.

Mitigation

Honor 429/Retry-After with backoff and a hard per-tool retry budget.

Provenance
