FLAWD-2026-0007

Required-but-omittable tool arg causes endless validation retry

A tool schema marks a variadic/optional argument as required. The model omits it, the validator rejects, and the agent retries the same broken call until budget death.

Failure mechanism

JSON-schema required[] incorrectly includes an optional *args-like field; validation failures are fed back without schema repair, producing a retry storm.

Reproduction

Prompt sent to the agent:

Call search_docs with query 'agent loops' and return the top hit.
  1. Tool schema requires phantom field `args`.
  2. Model omits it; vulnerable agent retries >N times.

Mitigation

Cap validation retries; fix or relax bad required fields instead of tight-looping.

Provenance

from public issue · field provenance: github-inspired

Source link

Optional *args marked required causing retry storms; adapted.

* PASS on examples/hardened_agent.py — a reference agent written for this repo, not a third-party product.
